### IP纯净度：先验证，再部署

这是整篇文章最值钱的一段。拿到新机器后，先别急着跑脚本，花两分钟做两件事：

1. 用 ipinfo.io 查这台IP的类型和归属地，看是hosting、business还是标了isp；
2. 用 scamalytics.com 查欺诈值（fraud score），分数越低越好。

两项都干净再部署节点。查出来不干净怎么办？销毁重开。多数云VPS都支持随时销毁、随时新开，新机器就是新IP。像Vultr这类按用量计费的商家，销毁后停止扣费，余额留着下次用，换一次IP的成本几乎可以忽略；包月制的商家重开一台就是新IP，但旧机器记得手动删掉，别白付一个月。

还有一种情况要留意：如果SSH压根连不上新开的机器，大概率是分到了被墙的IP，不用纠结，直接销毁重开，直到能连上为止。

## 搭建步骤：从开机到节点能连，六步走完

全程复制粘贴，不需要编程基础。以常见的Linux面板方案为例：

1. 选系统：开机时选 Ubuntu 22.04 或 Debian，都是长期支持版，脚本兼容性好。
2. SSH连上机器：Windows用Xshell或FinalShell，填IP、root账号和密码即可；Mac直接在终端输 `ssh root@你的IP`，输入密码登录。
3. 更新组件：Debian/Ubuntu 依次执行 `apt-get update -y` 和 `apt-get install curl -y`。
4. 跑一键脚本：推荐带网页面板的X-UI，装完可视化管理：`bash <(curl -Ls https://raw.githubusercontent.com/vaxilu/x-ui/master/install.sh)`；想用纯v2ray脚本也行：`bash <(curl -s -L https://git.io/v2ray-setup.sh)`。
5. 改端口、放行防火墙：安装过程中把默认端口改掉，装完如果连不上节点，执行 `sudo ufw disable` 关闭防火墙再试。
6. 客户端导入节点：Windows用Clash Verge（clash-meta内核），iOS和安卓用对应客户端，把节点信息导入就能连。

## 节点连上之后，这几件事别漏

搭好节点只是及格线，下面几件事没做，IP再干净也白搭。

DNS位置要和IP一致。IP显示在美国、DNS解析却走中国，环境照样露馅。解决办法是在节点端把DNS指定为IP所在国家的公共DNS，各国公共DNS列表在 public-dns.info 可以查到。

手机环境单独处理。节点解决的是网络层，手机本身也要配合：拔掉国内SIM卡或调整地区设置，iOS改成非中国区之后配合节点甚至可以不拔卡直接用。之前有案例是换了好几家节点直播都不出购物链接，最后发现是手机环境的问题——设备这一环别省。

一个账号固定一个环境。多个账号在同一节点上频繁切换地区、混着登录，等于主动给平台送关联线索。矩阵号就一个号配一个节点，各跑各的。

别把节点当机场用。BT下载、大量爬虫这类流量行为会让IP的使用画像变得可疑，不少代理配置可以在路由规则里直接屏蔽BT流量，建议保留。

## 常见问题

### 零基础能自己搭吗？

能。整套流程就是复制粘贴命令，一键脚本会自动完成配置，第一次搭慢一点也就半小时。

### 双ISP标签等于住宅IP吗？

不等于。双ISP只是ipinfo打的标签，市面上很多"伪家宽"被大量用户用烂之后，纯净度反而不如冷门机房的普通hosting IP。看IP别只看标签，欺诈值和使用历史更说明问题。

### 0播放，换VPS就能解决吗？

不一定。先确认手机环境没问题、账号没有违规记录；如果这些都没问题、新号依然0播放，再回头查IP质量。顺序反了容易白花钱。

### IP脏了或者被墙怎么办？

销毁重开换新IP。连SSH都连不上的机器基本可以判定为被墙IP，直接重开，不用纠结。

### 多少带宽够用？

一两个人做日常运营，300–500Mbps绰绰有余；直播建议1Gbps起步，并且回程线路优先。
